## 旧版奖励方案（已被 v2 分差回归取代）

- **v1 主线（已废弃）**：终局奖励 `r = sign(own_border − opp_border)`，
  胜 +1 / 负 −1 / 平 0，value 头回归该二元结果。缺点：输多输少无区别，
  先手大量败局下信用分配粗糙，易出现消极策略。
- **候选变体（当年备选，部分被 v2 采纳）**：
  - 分差奖励 `r = (opp_border − own_border) / B_max` 或 tanh 缩放
    —— 即现 v2 方案；当时顾虑「求大胜 vs 求胜」的目标偏移，
    后因线下计分本身按分差、且需解决先手摆烂而转为正式方案。
  - 势函数塑形：`Φ(s) = B_opp(s) − B_own(s)`，`r' = r + Φ(s') − Φ(s)`；
    本游戏棋子只增不减、局面单调前进（无环），γ=1 安全。
    可选邻近项 `Σ f(d)`，环距 `d = min(x, y, W−1−x, H−1−y)`。
    因引入人为中间偏好，未采用。

## 游戏性质发现（训练过程副产品）

1. **一层战术信号极强**：贪心（1 层分差）100:0 零封随机——「别自己填边、把对手推到边上」
   是这个游戏的战术核心。
2. **后手优势现象**：浅层战术水平上两个有差距的对手对局时后手全胜；同策略镜像对局则全平。
   9×9 多训几轮后纯策略网络也能双色全胜贪心——后手优势不是结构性的。
3. **评测的双稳定性**：训练中对贪心的快速评测在 0% / 50% / 75% / 100% 间跳变，
   几乎由先后手完全决定；消融实验必须按先后手拆分统计。
4. **纯 MCTS 弱于随机**（采样信号太弱），必须配合价值网络——AlphaZero 路线的必要性实证。
5. **全卷积网络尺寸无关性实证**：8×8 权重直接在未见过的 9×9/10×12 上前向正确
   （跨端误差 ~1e-5）、策略直落对随机 60:0。
6. **设备分工实测**（M4 Pro）：自博弈 worker = 多进程 + CPU 单线程（batch1 ~0.5ms/次推理），
   训练主进程 = MPS（batch256 ~14.5 万样本/s）。
7. **热重启陷阱（实测踩坑）**：续训时降 lr 且不继承 Adam 状态导致 loss 连升、评测崩塌；
   结论：续训要么继承优化器状态，要么保持原 lr。
8. **确定性对局不可靠**：argmax 直落会坍缩到一两条固定轨迹；浮点求和顺序的微小差异就能
   翻转近似打平的对局。近距离对比必须温度采样 + 足够局数 + 按先后手拆分。
9. **Elo 天梯的颜色陷阱**：配对平均分会掩盖「先手全输、后手全赢」的颜色决定论选手；
   选部署模型要看分色可靠性。
10. **风格相克**：模型间不存在线性实力序，不同形态/对手下强弱会反转。
11. **尺寸对比实测（8×8 vs 9×9）**：棋盘越大后手优势越大、颜色效应越剧烈；
    两尺寸落子风格惊人相似（约 80% 棋子在边环之外），差别不在「下哪」而在「结果结构」。
12. **跨尺寸评测会严重误判模型**：务必在本命尺寸测。
13. **奇偶假说被证伪**：颜色不对称由具体对手组合决定而非奇偶；
    主导因素：自博弈训练量 > 主场微加成 > 奇偶。
14. **深训买到的是鲁棒性不是确定性强度**：argmax 强度是脆弱的单轨迹技巧，
    采样鲁棒性才是真实棋力。
15. **贴目实测标定（9×9，旧模型）**：先手结算减 1 目可把对贪心的颜色不平衡从 36%/53%
    拉平到 48%/53%；顶级模型内战本身已近均衡。规则级平衡需用修正 PUCT 后的模型重新标定。

## 游戏理论视角：最优解与先后手

- 牛顿棋是有限、完全信息、零和博弈，按 Zermelo 定理必有「先手必胜 / 后手必胜 /
  双方最优则和局」之一；但实验无法判定是哪一种（状态空间上限 3^81 ≈ 10^38）。
- 实证硬结论：后手 tempo 优势显著且贯穿所有水平层（顶级模型互搏仍有 ~75% 胜率，
  160 局采样实测）；但它不是绝对优势，更强玩家可以克服颜色劣势。
- 待解变数：① 博弈论真值；② 后手优势在超人类水平是否缩小/反转；
  ③ 棋盘奇偶性影响；④ 和局频率与风格镜像的关系；⑤ 多人局博弈。
- 回答「谁有最优解」的两条路：AlphaZero 规模扩大几个数量级观察 value 收敛；
  或写显式求解器从小棋盘（4×4/5×5 可完全求解）外推规律。
